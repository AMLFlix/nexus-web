How to Buy

ဝယ်ယူရန် အဆင့် ၃ ဆင့်

1. ငွေလွှဲပြောင်းပါ

အောက်ပါအကောင့်များထဲမှ တစ်ခုသို့ ကျသင့်ငွေကို လွှဲပေးပါ။ (Copy ကူးရန် နှိပ်ပါ)

2. နောက်ဆုံး ၄ လုံး မှတ်ထားပါ

ငွေလွှဲပြီးပါက ပြေစာ (e-Receipt) ပေါ်ရှိ Transaction ID ၏ နောက်ဆုံး ဂဏန်း ၄ လုံးကို မှတ်ထားပါ။

Transaction ID

21084589

3. App တွင် အတည်ပြုပါ

Nexus App သို့ဝင်ကာ Settings > Buy Premium တွင် ထို ၄ လုံးကို ထည့်သွင်းပါ။ မိနစ်ပိုင်းအတွင်း Premium ရရှိပါမည်။

FAQ

ငွေလွှဲပြီး ချက်ချင်းရမှာလား?
App ထဲတွင် Transaction ID ၄ လုံးကို မှန်ကန်စွာ ထည့်သွင်းပြီးပါက စနစ်မှ စစ်ဆေးပြီး မိနစ်ပိုင်းအတွင်း Premium အသုံးပြုနိုင်မည် ဖြစ်ပါသည်။
အကောင့်တစ်ခုကို စက်ဘယ်နှလုံး သုံးလို့ရမလဲ?
အကောင့်တစ်ခုတည်းကို စက်အများကြီးတွင် လော့အင်ဝင်ထားနိုင်ပါသည်။ သို့သော် တစ်ချိန်တည်းတွင် စက် (၂) လုံး (2 Screens at a time) အထိသာ ပြိုင်တူ ကြည့်ရှုနိုင်ပါသည်။ (ဥပမာ- ဖုန်းနှင့် TV တပြိုင်နက်ကြည့်နိုင်သည်)
iPhone (iOS) တွင် ရနိုင်မလား?
လက်ရှိတွင် Android (ဖုန်း၊ Tablet, TV) များအတွက်သာ ရရှိနိုင်သေးပါသည်။ iOS version ကို မကြာမီ ထုတ်လုပ်ပေးသွားပါမည်။
