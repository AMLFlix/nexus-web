How to Subscribe

1

Transfer Payment

အောက်ဖော်ပြပါ အကောင့်တစ်ခုခုသို့ သင်ရွေးချယ်ထားသော Plan အတွက် ကျသင့်ငွေကို လွှဲပေးပါ။ (Account Number ကို နှိပ်ပြီး Copy ကူးပါ)

2

Note Transaction ID

ငွေလွှဲပြေစာ (e-Receipt) ပေါ်ရှိ Transaction ID နောက်ဆုံး ဂဏန်း ၄ လုံး ကို မှတ်ထားပါ။

3

Activate in App

Nexus App ၏ Settings > Get Premium တွင် ထိုဂဏန်း ၄ လုံးကို ထည့်သွင်းပြီး အတည်ပြုလိုက်ပါက မိနစ်ပိုင်းအတွင်း Premium ရရှိပါမည်။

Frequently Asked Questions

ငွေလွှဲပြီးတာနဲ့ ချက်ချင်း ကြည့်လို့ရမှာလား?

App ထဲတွင် Transaction ID ၄ လုံးကို မှန်ကန်စွာ ထည့်သွင်းပြီးပါက စနစ်မှ အလိုအလျောက် စစ်ဆေးပြီး မိနစ်ပိုင်းအတွင်း Premium အသုံးပြုနိုင်မည် ဖြစ်ပါသည်။

အကောင့်တစ်ခုကို စက်ဘယ်နှလုံး သုံးလို့ရမလဲ?

အကောင့်တစ်ခုတည်းကို စက်အများကြီးတွင် လော့အင်ဝင်ထားနိုင်ပါသည်။ သို့သော် သင်ဝယ်ယူထားသော Plan အပေါ်မူတည်ပြီး တစ်ချိန်တည်းတွင် ပြိုင်တူကြည့်ရှုနိုင်သော စက်အရေအတွက် ကွာခြားပါမည် (ဥပမာ - Standard Plan သည် တစ်ပြိုင်နက် ၂ လုံး ကြည့်နိုင်ပါသည်)။

iPhone (iOS) တွင် ရနိုင်မလား?

လက်ရှိတွင် Android (ဖုန်း၊ Tablet, Android TV, TV Box) များအတွက်သာ App ရရှိနိုင်သေးပါသည်။ iOS version ကို မကြာမီ ထုတ်လုပ်ပေးသွားပါမည်။
